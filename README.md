## Preuves publiques

### Plateformes

- [kube-aegis-forge](https://github.com/murillo-consulting/kube-aegis-forge) — chaîne GitOps Kubernetes reproductible, artefacts signés et contrôles de supply chain.
- [BastShield](https://github.com/murillo-consulting/BastShield) — plateforme Kubernetes souveraine avec Talos, OpenTofu, GitOps, OpenBao et opérations déconnectées.
- [Labz](https://github.com/murillo-consulting/Labz) — cyber range AWS reproductible pour entraînement, simulation d'attaque et validation des détections.

### Systèmes sécurisés et auditables

- [langgraph-resilient-agent](https://github.com/murillo-consulting/langgraph-resilient-agent) — agent durable avec approbation humaine, outils idempotents et workflows auditables.
- [spring-ai-secure-rag](https://github.com/murillo-consulting/spring-ai-secure-rag) — service RAG de référence avec isolation par tenant et citations construites côté serveur.
- [impots-france-mcp](https://github.com/murillo-consulting/impots-france-mcp) — serveur MCP fiscal français auditable en Rust/Wasm sur Cloudflare Workers.

### Outillage
